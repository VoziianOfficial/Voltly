Matching logic

The right category helps make provider conversations cleaner.

A panel upgrade request is not the same as a lighting request. EV charger planning can involve capacity questions. Wiring can depend heavily on access and renovation conditions. keeps these paths separated so homeowners can compare more clearly.

Wiring Rooms / access / renovation context
EV charger Charger location / panel review context
Lighting Fixtures / layout / indoor-outdoor scope
